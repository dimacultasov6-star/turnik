# Турник (Turnik)

Оригинальная физическая игра про сальто и трюки на перекладине для Android.
Написана с нуля: физика маятника, полёта, вращения и захвата перекладины — весь код и графика созданы в этом репозитории, никаких чужих ресурсов не используется.

**Сайт со скачиванием:** https://dimacultasov6-star.github.io/turnik/  
**APK напрямую:** https://github.com/dimacultasov6-star/turnik/releases/download/v1.0/Turnik-1.0.apk

## Управление

| Кнопка | На клавиатуре | Что делает |
|---|---|---|
| **ТЯНИ** | `Пробел` / `W` / `↑` | На турнике — раскачка. В воздухе — поджать ноги, сальто крутится быстрее |
| **ОТПУСТИ** | `S` / `↓` / `Enter` | Отпустить перекладину и полететь |
| **↺ ↻** | `←` `→` / `A` `D` | Докрутить или замедлить вращение |
| **R** | `R` | Возрождение на ближайшем турнике |

## Правила

- раскачайся (**ТЯНИ**), отпусти перекладину в нужный момент и долети до следующей;
- в полёте поджимай ноги, чтобы набрать сальто, и докручивай вращение стрелками;
- приземляйся на ноги или лови перекладину — за каждый флип начисляются очки, серия даёт комбо;
- падение обрывает серию.

Рекорд сохраняется локально.

## Установка на телефон

1. Скачай `Turnik-1.0.apk` из этого репозитория.
2. Открой файл на телефоне и разреши установку из неизвестных источников.
3. Играй.

APK подписан самоподписанным ключом (для Play Market не предназначен, это side-load сборка).

## Сборка APK

Требования: Windows, Android SDK (build-tools 36.0.0, platforms android-36), Android Studio JBR (Java), Node.js не обязателен.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт по шагам:

1. копирует `web/` и `android/` во временную папку с ASCII-путём;
2. `aapt2 compile` + `aapt2 link` — манифест и векторная иконка;
3. `javac` — `MainActivity` (WebView-обёртка), байткод Java 8;
4. `d8` — `classes.dex`;
5. складывает dex и веб-игру в APK, `zipalign`, подпись `apksigner`;
6. кладёт готовый `Turnik-1.0.apk` в корень репозитория.

## Как это работает

- **Маятник**: перекладина — точка подвеса, при нажатии «ТЯНИ» к телу прикладывается момент в стороне движения, поэтому амплитуда растёт, в том числе до полных оборотов.
- **Полёт**: после отпускания тело летит по баллистике, «ТЯНИ» уменьшает момент инерции (поджим) и разгоняет вращение, стрелки добавляют момент.
- **Захват**: проверяется положение виртуальных рук относительно капсулы перекладины, скорость подвеса вычисляется из тангенциальной составляющей скорости.
- **Приземление**: чистым считается приземление на ноги с допустимой скоростью вращения, иначе падение.

## Тесты

Логика проверяется скриптом `test_game.js` (Node, стабы DOM): раскачка, отрыв, полёт, флипы, приземление, падение, захват, очки и комбо.
